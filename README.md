# صفّاق الفرقة

**تحميل آخر إصدار:** https://github.com/alyoushw/saffaq-alfirqa/releases/latest/download/saffaq-alfirqa.apk

التطبيق ينبّه بنفسه إذا نزل إصدار جديد، وتقدر تحدّثه من داخله.

تطبيق أندرويد يولّد صفقة الأيادي للفرق الإنشادية.

## وش يسوي

- **صفقة على مقطع:** ترفع إنشاد (صوت أو فيديو) أو تسجّله بالمايك، والتطبيق يحلّل الإيقاع (السرعة، الضربات، بداية المازورة) ويركّب عليه صفقة، حتى لو المقطع ما فيه صفقة أصلاً.
  - أنماط جاهزة: بسيط، هادئ روحاني، مولد، حماسي. ويقدر المستخدم يعدّل الأشخاص والتشكيل بنفسه.
  - تصحيح الإيقاع: السرعة ×٢ أو ÷٢، تحريك بداية المازورة، الضبط بالنقر مع الإيقاع، تقديم الصفقة أو تأخيرها، وتحديد بداية الصفقة ونهايتها.
  - التصدير: فيديو مع الصفقة (MP4)، الصوت مع الصفقة، الصفقة لحالها (M4A أو WAV).
- **الاستوديو:** مكتبة فيها ١٠ أنواع صفقات، ولكل شخص صفقته ومتى يصفق، ثم الدمج والتصدير. ويقدر المستخدم يضيف صفقته من ملف أو بالتسجيل.

## البنية

- `www/`: واجهة التطبيق (HTML/JS بدون أدوات بناء).
  - `js/dsp.js`: تحليل الإيقاع (spectral flux، تقدير السرعة، تتبّع الضربات بالبرمجة الديناميكية، بداية المازورة).
  - `js/engine.js`: محرّك الصوت (المكتبة، الأشخاص، الصدى، WAV).
  - `js/tracks.js`: محرّر الأشخاص والأنماط.
  - `js/io.js`: الحفظ والمشاركة ودمج الفيديو.
  - `sounds/`: أصوات الصفقات (مولّدة بـ ElevenLabs ومقصوصة صفقة صفقة).
- `android/`: مشروع Capacitor 7.
  - `MediaToolsPlugin.java`: دمج الصوت مع الفيديو، وتحويل WAV إلى M4A (MediaCodec وMediaMuxer)، والحفظ في مجلدات الموسيقى والأفلام.

## البناء

```bash
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

يحتاج Java 21 وAndroid SDK 35.

## النشر التلقائي

كل تعديل يُرفع على `main` يبنيه GitHub Actions (`.github/workflows/release.yml`) ويوقّعه، ثم ينشره كإصدار جديد. والتطبيق يتأكد من آخر إصدار عند كل فتح.
يحتاج سر واحد في المستودع: `SIGNING_PASSWORD` (كلمة سر فك تشفير `android/release.keystore.enc`).
